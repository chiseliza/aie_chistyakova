# Тесты проекта

- test_health_endpoint - Интеграционный
Запрос к /health для проверки готовности сервиса
Статус 200, ответ содержит {"status": "ok", "model_loaded": ...}

 - test_predict_endpoint_missing_fields - Интеграционный
Отправка запроса с неполным набором полей
Статус 200 (если модель устойчива) или 400/422 (валидация) — корректная обработка ошибки

- test_predict_endpoint_invalid_stops - Интеграционный
Отправка невалидного значения в категориальном поле stops
Статус 400/422 (валидация) или 500 (если ошибка не перехвачена) — система не падает молча

- test_clean_data_removes_outliers - Модульный 
Проверка фильтрации выбросов по признаку длительность перелета

Команда запуска тестов:

```bash
cd project
pytest tests/ -v
```

Наличие даже простых тестов поможет избежать «ломающих» изменений перед защитой.
