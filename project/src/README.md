# Исходный код проекта

Структура основного кода:
- `src/data/` — загрузка и подготовка данных, работа с признаками
- `src/models/` — обучение и применение моделей
- `src/service/` — запуск сервиса
- `src/utils/` — вспомогательные функции (загрузка конфигов, логгирование)

Точки входа:

- `python -m src.prepare` - загрузка и подготовка данных
- `python -m src.train` - инициализирование и обучение модели
- `python -m src.api_predict` - запуск сервиса, предсказание
