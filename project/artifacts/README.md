# Артефакты проекта

- logs:
logs.log - файл логов
- metrics:
artifacts\metrics\metrics_compare.csv - сравнительная таблица выбранных моделей
artifacts\metrics\metrics.json - метрики лучшей модели
- models:
artifacts\models\best_model.pkl - лучшая модель с подобранными гиперапаметрами
- plots:
artifacts\plots\correlation.png - тепловая матрица для предобработанных признаков
artifacts\plots\target.png - график распределения целевой переменной
